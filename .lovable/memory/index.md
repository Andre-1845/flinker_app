# Project Memory

## Core
Flinker: marketplace for freelancers + temporary jobs. Navy blue (#0c1425) + orange (#F97316). Mobile-first, dark theme.
Portuguese (pt-BR) UI language. Inspired by Uber/iFood/Tinder.
Lovable Cloud enabled. DB tables: profiles, wallets, transactions, wallet_movements, withdrawals, fraud_alerts, gig_payments, platform_config, user_roles, notifications.

## Memories
- [Brand & Design](mem://design/brand) — Color palette, typography, motion style
- [Financial System](mem://features/financial-system) — Wallet, commission, anti-fraud, chat filter, Pagar.me integration plan
- [Auth System](mem://features/auth) — Email + Google OAuth, role-based signup, protected routes
- [Gig System](mem://features/gig-system) — Gigs table, gig_matches with bilateral accept, schedule conflicts, cancellation penalties
- [Reputation System](mem://features/reputation-system) — Bilateral reputation with 5 pillars, gamification levels, and match impact
- [Verification System](mem://features/verification-system) — Verification subscription with badges and match boost
- [Match System](mem://features/match-system) — Real swipe-to-match: worker swipe creates gig_match + notifies company via notifications table
